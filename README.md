# CAN Diagnostic Tap

A Python workspace for CAN diagnostics with two peer tools:

- `can-diag-trace`: trace analyzer for `.asc` / `.blf` and plugin-driven protocol decoding
- `can-diag-console`: interactive live diagnostic console

Package-specific documentation lives here:

- [can_diag_trace/README.md](can_diag_trace/README.md)
- [can_diag_console/README.md](can_diag_console/README.md)
- [diag_defs/README.md](diag_defs/README.md)
- [diag_filter/README.md](diag_filter/README.md)

**Disclaimer:** These tools are for **educational and personal use only**. Use responsibly and only with authorization on systems you own or have explicit permission to analyze.

This started as a vibe coding hobby project and is provided as-is.
